# Base litúrgica local — Santa Luzia

Este diretório é o ponto oficial para o conteúdo litúrgico empacotado no projeto.

## Estrutura

Os arquivos diários autorizados devem ficar em:

`content/liturgia/dias/AAAA-MM-DD.json`

Cada arquivo pode conter:

- celebração e tempo litúrgico;
- cor litúrgica;
- Primeira Leitura;
- Salmo Responsorial;
- Segunda Leitura, quando houver;
- Evangelho;
- orações da coleta, oferendas e comunhão;
- Santo do Dia;
- caminho de uma imagem local;
- identificação da fonte/licença.

O aplicativo procura primeiro essa base local. Quando um dia autorizado estiver presente, a Liturgia e o Quiz Litúrgico usam exatamente o mesmo registro.

Não adicionar aqui textos, imagens ou bancos de dados extraídos de aplicativos, livros ou serviços de terceiros sem licença ou autorização para redistribuição. O repositório do Santa Luzia é público.

A arquitetura aceita conteúdo próprio, em domínio público ou devidamente licenciado.
