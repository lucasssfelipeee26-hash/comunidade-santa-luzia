INSTALAÇÃO
1. Pare o site com Ctrl + C.
2. Extraia este ZIP.
3. Copie app, components e lib para a pasta principal do projeto.
4. Escolha "Substituir os arquivos no destino".
5. Execute:
   Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
   npm run dev

Não é necessário executar npm install.
Este update não altera a pasta data nem apaga escalas/cadastros existentes.
